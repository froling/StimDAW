## Vision (12 months)

Pattern-looper med live performance controls — Ableton Session View för e-stim. Pattern bank,
scene launcher, MIDI-mappade controls, performance recorder. Solo-optimerad UX (en hand, stor
synlig STOP, lugn play-yta). Mock-driven utveckling så GUI och scheduler kan iteras utan
hårdvara.

## Premise locks (Step 0A)

- **USER:** Solo. En hand. Mottagaren styr själv. ESC/STOP pinky-distance.
- **PARADIGM:** Repetitiva pattern-loops i repetition med live-modulation (drum machine /
  Ableton Session View). Recording = automation av controls över tid, INTE audio.
- **WEDGE α:** Live monitor + CLI passthrough, byggt mot mock firmware. Ingen pattern-UI än.
- **STACK:** Vite + TypeScript + Svelte 5 + Web Serial API. Bun som package manager
  och `bun test` som test runner (snabbt, native, perfekt för logik-tester i protocol/
  mock/fileformat-modulerna). Tauri-migration är trivial (samma frontend, byt transport-
  modul) om/när vi behöver native serial eller fullt filsystem — fortfarande NeoDK-only.
- **TRANSPORT-INTERFACE:** `Transport`-interface med 2 implementations från start
  (`web-serial.ts`, `mock.ts`). 30 min mer arbete nu, sparar dagar senare.

## Non-goals (hela projektet, inte bara α)

Beslutat 2026-04-29: **StimDAW är NeoDK-only.** Hårda non-goals som är "förbjudna att smyga in":

- **Multi-protokoll-stöd.** Ingen abstraktion för zc95, FOC-Stim, ET-312, e-stim-pl etc. Protokoll-lagret är NeoDK-specifikt — ingen "Protocol"-interface, inga adapter-lager.
- **Multi-device.** En NeoDK i taget. Inga "device manager", ingen multi-port-skanning.
- **Generic e-stim platform.** Vi bygger inte "en DAW för alla e-stim-enheter". Vi bygger ett verktyg för den hw vi har.

## Eng-review locks (2026-04-29)

**Architecture (Section 1):**
- File layout: 5 modules + `src/safety/` + `src/log.ts` + `src/ui/`. ~16 src + ~14 test-filer.
- Mock firmware på MAIN thread med virtuell tid (slow JS = simulated time pauses; tester deterministiska, ej realtid).
- Protocol = pure TS + EventEmitter; UI = Svelte 5 runes; `ui/stores.svelte.ts` är adapter.
- **Disconnect-flöde:** ingen auto-reconnect. Red banner → manuell reconnect.
- **`src/safety/ramp-controller.ts`** (NY): på disconnect → internal amplitude=0 + persist lastKnown.
  På reconnect → smooth ramp 0→lastKnown över `rampUpDuration` (5s default, persist:ad i .stimdaw + localStorage).
  STOP cancelar ramp omedelbart.
- Frame parser: stateful (Web Serial chunks splittar frames mid-byte; måste buffer:as).

**Code quality (Section 2):**
- Custom error classes (TransportError, FrameError, CrcError) som discriminated union.
- Typed attribute reads: `client.read<T>(AttributeId.Voltages) → Voltages` via TS map-type.
- Tunn custom logger (`src/log.ts`) med levels.

**Tests (Section 3):**
- Bun test + `fast-check` property-tester på crc.ts, frame.ts, descriptor.ts.
- UI komponent-tester deferred till β.
- Full integration-coverage för säkerhetspaths (disconnect-ramp, reconnect-ramp, STOP).
- Critical paths flagged (test plan-fil): CRC silent drops, ramp-controller (4), voltage-sim, queue.

**Performance (Section 4):**
- **En enda monotonisk simulerad-tid-scheduler** (per outside-voice R1) — priority queue, advance till nästa event eller +16ms. Inga dual-clock sync-buggar.

**Outside voice (Claude subagent — Codex unavailable):**
- 7 findings silent-adds (1, 3, 4, 6, 8, 12, 14): force re-zero på app-restart, STOP end-to-end + watchdog, Page Visibility → safety-stop, identify-probe på connect, filformat migration-harness, HW arrival-checklist, identity-scrubbing-policy.
- 6 cherry-picks accepted (R1-R5 + R6 disagree-with-subagent).
- Codegen promoterades från TODOS till α-scope (R2).

## Hardware arrival checklist (när PCB landar)

Innan output enableras första gången på riktig hw:

1. Read AI_VOLTAGES, cross-checka Vbat mot multimeter (±10%). Inga elektroder anslutna.
2. Read AI_FIRMWARE_VERSION, verifiera matchande version i submodulen.
3. Subscribe AI_VOLTAGES, observera idle-Vcap-laddningskurva.
4. Skicka /v (firmware version) via Debug NST, verifiera respons.
5. Bara därefter: anslut elektroder, börja med /0 (intensity=0), ramp manuellt upp.
