# CEO Plan: StimDAW α2 — PT-descriptor stack + N-rad oscilloscope
Generated by /plan-ceo-review on 2026-04-30
Branch: main | Mode: SELECTIVE EXPANSION
Repo: froling/StimDAW

## Vision (12 months)

Pattern-looper med live performance controls — Ableton Session View för e-stim.
α2 är **bryggan** mellan α1 (infrastruktur) och β (pattern-editor + scene-launcher):
α2 ger den första dogfood-able produkten där användaren faktiskt kan
*se vad boxen genererar* per elektrod-kombination. Utan denna feedback-loop
flyger β blint.

## Premise locks

- **WEDGE α2:** PT-descriptor protokoll-stack (host → mock → rendered waveform)
  + dynamisk N-rad oscilloscope (en rad per unik elcon i pattern).
- **Inte realtidsklocka.** Plot per descriptor, sluten chunk åt gången.
- **nr_of_pulses lågt och fast** (host-side konvention, inte protokoll-tvång).
  Default: ~2-20 per descriptor. Patterns består av många små descriptors
  i sekvens.
- **Modulär uppbyggnad.** Varje komponent är egen commit: data-modell →
  encoder → mock-queue → waveform-render → oscilloscope-UI → CSV-validation.

## Datamodell — dynamisk elcon-array (ej 9 hardcodade par)

Direkt port från `reference/NeoDK/firmware/src/patterns.c`:

```typescript
type ElectrodeMask = number; // 0..15, bitmask: A=1, B=2, C=4, D=8
type Elcon = readonly [pos: ElectrodeMask, neg: ElectrodeMask];

interface PatternDef {
  name: string;
  elcons: readonly Elcon[];   // dynamisk längd: 2 (Jackhammer) → 18 (Circle)
  paceMicros: number;          // tid mellan starts av on-konsekutiva pulser
  nrOfSteps: number;           // ramp-up steps inom pattern
  nrOfReps: number;            // hur många gånger pattern cyklas
}
```

**Hård invariant** (verifieras vid load, samma som firmware `checkPattern`):
```
för varje elcon: (pos & neg) === 0  // pos och neg får inte överlappa = kortslutning
```

## Hardware constraints (från firmware-källan)

```
Switch matrix:        4× TLP268J opto-triacs (U4-U7)
Electrodes:           4 (A, B, C, D)
Electrode bitmask:    A=1, B=2, C=4, D=8 (per patterns.c EL_A..EL_D enum)
Disjunktums-rule:     (pos & neg) === 0 — annars kortslutning
Sub-queues:           2 (per fas) × 20 slots each (sequencer.c)
Pulse pace:           min ~7 ms (MAX_PULSE_PACE_µs konstant), max godtycklig
Pulse width:          max 200 µs per spec
Amplitude byte:       0..255 (1/255 av maxspänning, ~80V vid 9V batteri)
nr_of_pulses:         u16 (0..65535) — vi konventionellt håller lågt (~2-20)
```

## Eng-review locks (2026-04-30)

**Architecture:**
- **E1 reframe** (post outside-voice): rendering är **envelope-segments**, inte 50µs samples.
  Descriptor → array av `{t_start, t_end, amp_signed, elcon_index}`. SVG `<rect>` per
  pulse-pair. Cuts memory ~10×, ingen canvas behövd.
- **E2:** Streaming render från SimClock dispatch → ringbuffer per elcon.
- **E3:** 3-layer split (PatternRunner → PtQueue → Waveform) — matchar firmware-mental-modell.

**Code Quality:**
- **E4:** Plain `number` ElectrodeMask + named consts (A=1, B=2, C=4, D=8). Helpers
  `isDisjoint`, `union`, `maskToString`.
- **E5:** Type-safe Descriptor builder med explicit omit-flags. Round-trip property tests.
- **E6:** Lenient CSV parser (accepterar både Intense.csv och Orgasm_*.csv format).

**Performance:**
- **E7 reframe:** Fast 5s window per elcon (drop adaptive-logic per outside-voice #6).
  Memory försumbart efter envelope-reframe.
- **E8:** Default cycle-restart, perf-test triggar warning vid >100ms overhead.

**Outside-voice silent-adds (alla locked):**
- **#1: Replay tolerance bands** — `±50µs timing, ±5% amplitude` i alla CSV-replay-tester.
  JS event-loop jitter på Windows är upp till 16ms — strikt match är inte rimligt.
- **#3: Single chokepoint amplitude clamp** — `effective = min(rampAmp × descriptorAmp ×
  ceiling, 255)` på *en* plats i `waveform.ts`. Hardcoded MAX (255) kan ej överskridas.
- **#4: Disjunktums-regel enforcas vid `ptQueue.enqueue()`** — belt-and-suspenders.
  Builder validerar, queue validerar igen.
- **#5: STOP-during-stuck-queue critical-test** — fyll queue till overflow, fire STOP,
  verifiera drain händer FÖRE pending dispatches och utan ny output.
- **#11: Definition of Done för α2:** "Klar när alla 4 patterns312-CSVs replay:ar inom
  ±50µs/±5% tolerance AND oscilloscope visar Toggle's 4 + Circle's 18 elcon-rader korrekt
  grupperade."

**Outside-voice deferred till β (när hw landar):**
- **#2** patterns312 provenance — verifiera firmware-version som producerade traces.
- **#12** Web Serial reconnect mid-pattern — pt-queue draining vid drop.

## Design Review locks (2026-04-30)

**Approved direction:** B-modified, X/Y plot (`approved.html` saved to
`~/.gstack/projects/froling-StimDAW/designs/oscilloscope-20260430/`).

**Critical reframe from CEO scope:** Oscilloscope-panelen är **pure visualization** —
INGA controls (pattern selector, run/stop, step counter) i panelen. Styrning sker i
andra paneler. Per user: "se detta som en modul som vi ska ha i ett helhetsgränssnitt".

**Modul-kontext (helhetsgränssnitt):**

```
α1 paneler (befintliga): Monitor, IntensitySlider, Cli, ConnectionBanner, StopButton
α2 panel (ny):           Oscilloscope (denna modul)
β panel (kommande):      DAW (pattern editor / scene launcher) — höger sida, tar vi sen
```

**Locked rendering decisions:**

| Aspekt | Val |
|---|---|
| Render-typ | X/Y plot, **line-only** (ingen dots — 200+ samples = visual noise) |
| amp trace | **Step-line** (horizontal + vertical segment) — tekniskt korrekt: amp konstant inom descriptor |
| Vcap trace | **Smooth line** — kontinuerlig RC-fysik |
| Iprim trace (future) | Smooth line med pulse-spike-emphasis |
| Sampling rate | 30ms per sample (~33Hz visualization rate) |
| Time window | 6s default rolling, 5-10s configurable i settings (annan panel) |
| Samples per rad | 200 (= 6s × 33Hz) |
| Newest data | Höger kanten, rullar vänster |
| Row height | 56px (B-derived spacing) |
| Hidden row | 24px collapsed greyed strip |
| Per-row toggle | Eye icon ●/○ klickbar |
| Trace legend | Klickbar — toggla traces on/off för alla rader |
| Multi-trace | Flera överlagrade i samma SVG, färgade per metric |
| Cursor | 1px subtle grå linje, info från extern modul (inte interaktiv) |

**Implementation reference:** Mockupens `<script>`-block är en fungerande renderer
— samma seedade PRNG + step-line/smooth-line builders kan portas direkt till TS.
Pure SVG, inga deps. Approved-filen committas till repo som `docs/designs/`.
